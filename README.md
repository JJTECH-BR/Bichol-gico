# 🐾 Bichológico

Um projeto web moderno e responsivo, focado em alta performance e em uma interface amigável. 

Este projeto foi construído utilizando um ecossistema atualizado de desenvolvimento front-end e back-end leve, garantindo uma navegação rápida e estruturada.

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido com as seguintes tecnologias:

*   **[React 19](https://react.dev/)**: Biblioteca principal para a construção da interface de usuário.
*   **[Vite](https://vitejs.dev/)**: Ferramenta de build extremamente rápida para o desenvolvimento.
*   **[Tailwind CSS](https://tailwindcss.com/)**: Framework de CSS utilitário para estilização rápida e responsiva.
*   **[Hono](https://hono.dev/)**: Framework web ultrarrápido e leve para gerenciar rotas e APIs.
*   **[Zod](https://zod.dev/)**: Validação de esquemas e dados de ponta a ponta.
*   **[React Router](https://reactrouter.com/)**: Gerenciamento de rotas no front-end.
*   **[Lucide React](https://lucide.dev/)**: Biblioteca de ícones bonitos e consistentes.
